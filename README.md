# 🚀 Overview

**DLI Launcher** is a next-generation desktop Minecraft launcher built for the **DLI Gaming Platform**.

Designed with a premium user experience in mind, DLI Launcher combines modern interface design, high performance, secure authentication, and intelligent Minecraft management into one powerful application.

It is not just a launcher.

It is the gateway to the **DLI ecosystem**.

# ⚙️ Installation

## Requirements

- Windows 10 / Windows 11
- .NET 9 SDK
- Node.js 20+
- Java Runtime Environment
- Minecraft Java Edition

---

## Setup

Clone the repository:

```bash
git clone https://github.com/DLI-Studios/DLI-Launcher-Source.git
```

Enter the project:

```bash
cd DLI-Launcher-Source
```

Install dependencies:

```bash
npm install
```

Run development mode:

```bash
npm run dev
```
