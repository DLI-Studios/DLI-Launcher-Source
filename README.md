# 🚀 Overview

DLI Launcher is a modern desktop launcher built for the **DLI Gaming Platform**.

Designed with a premium user experience in mind, it combines modern UI, fast performance, secure authentication and seamless Minecraft management into a single application.

---

# ✨ Features

- 🔐 Discord OAuth (PKCE)
- 📧 Firebase Email Authentication
- 👤 Custom Player Profiles
- 🖼 Avatar Upload Support
- 🎮 Minecraft Version Manager
- ⬇ Automatic Downloads
- 🔄 Self Updating Launcher
- ⚡ Single Instance Protection
- 🎨 Modern Glassmorphism UI
- 🌙 Dark Theme
