# Architecture

DLI Launcher combines web technology flexibility with native desktop performance.

```
                 DLI LAUNCHER

                     USER

                      │

              Premium Interface

                      │

        ┌─────────────┴─────────────┐

        React + TypeScript       WPF Core

        │                         │

        │                    C# Services

        │                         │

        └─────────────┬─────────────┘

                      │

              Minecraft Engine

                      │

                 CmlLib.Core

                      │

              Minecraft Runtime
```

| Layer | Technology |

# Developer Information

## Requirements

- Windows 10 / 11
- .NET 9 SDK
- Node.js 20+

## Installation

```bash

cd DLI-Launcher-Source

npm install

npm run dev
```
